# 💰 Expense Tracker

A full-stack Expense Tracker web application that helps users manage their personal income and expenses in one place.

The application provides secure user authentication, income and expense management, dashboard analytics, profile management, and Excel report downloads.

## 🚀 Live Demo

[Expense Tracker - Live Website](https://expense-tracker-1-f2xm.onrender.com)

## 📌 Features

- 🔐 User Registration and Login
- 👤 User Profile Management
- 🖼️ Profile Image Upload
- 💰 Add and Manage Income
- 💸 Add and Manage Expenses
- 🗑️ Delete Income and Expenses
- 📊 Dashboard with Financial Summary
- 📈 Income and Expense Charts
- 📋 Recent Transactions
- 📅 Last 30 Days Income and Expenses
- 📅 Last 60 Days Income and Expenses
- 📂 Expense Category-wise Analysis
- 📥 Download Income Data as Excel
- 📥 Download Expense Data as Excel
- 🔒 Protected API Routes
- 📱 Responsive User Interface
